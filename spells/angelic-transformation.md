# Angelic Transformation

- Type: [World Map] Major Race Transformation
- Casting cost: 600 Mana
- Casting points: 600
- Tome: Tome of Exaltation
- Granted by: [Masters of Order](../world/free-cities.md) (free city)
- DLC: Base

Turns the target race into angelic beings, granting them:

- The Celestial unit type.
- Flying Movement, which increases mobility.
- Faithful, which reduces Unit Upkeep.
- Decreased number of units in formation.
