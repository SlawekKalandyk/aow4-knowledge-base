# Awaken Instincts

- Type: [Combat] Healing/Buff Spell
- Casting cost: 150 Mana
- Casting points: 50
- Tome: Tome of Nature's Wrath
- DLC: Base

All friendly units in a 2-hex radius:

- Heal +25 Temporary Hit Points.
- Regain all Action Points.
- Become Berserk for 2 Turns.

Does not affect units with Control Loss Immunity.
