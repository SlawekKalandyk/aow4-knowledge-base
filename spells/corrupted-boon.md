# Corrupted Boon

- Type: [Combat] Debuff Spell
- Casting cost: 20 Mana
- Casting points: 25
- Tome: Tome of Corruption
- Granted by: [Masters of Corruption](../world/free-cities.md) (free city, always), [Masters of Corruption](../world/free-cities.md) (free city, possible upgrade)
- DLC: ELDRITCHREALMS

Target enemy unit:

- Loses all Positive Status Effects.
- If a lost status effect has any Status Effects Countering, then the unit gains a stack of that Negative Status Effect.
