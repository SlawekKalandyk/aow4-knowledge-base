# Final Ultimatum

- Type: [Combat] Debuff Spell
- Casting cost: 45 Mana
- Casting points: 30
- Tome: Tome of Subjugation
- DLC: Base

Target Routing non-Hero enemy unit:

- Has a base 90% chance of becoming permanently mind controlled.
- If successful, it gains +60 Morale.
- If resisted, the unit dies instead.
