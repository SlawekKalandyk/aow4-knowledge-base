# Pure Soul

- Type: [World Map] Minor Race Transformation
- Casting cost: 450 Mana
- Casting points: 450
- Tome: Tome of the Archon
- DLC: ARCHONPROPHECY

Purify the souls of target race, granting them:

- At the start of each turn in combat, dispel 1 Negative Status Effect.
- If the Negative Status Effect removed had a positive counter, gain the Positive Status Effect.

This transformation is incompatible with Umbral Flesh and Gloom Strider.
