# Mark of the Butcher

- Type: destiny trait
- Point cost: 1
- Affinity: -10 Alignment
- DLC: Base

## Effects

- -10 Alignment
- Units of this race earn +50% XP Experience in combat.
- Cities of this race lose -2 City Stability for each Population.

## Description

Brutalized by constant battles, they turn any conflict into carnage.
