# Desert Adaptation

- Type: form trait
- Point cost: 1
- Group: Adaptations
- DLC: Base
- Incompatible with: Arctic Adaptation, Desolate Adaptation, Swamp Adaptation, Underground Adaptation
- Grants spells: [Earthshape: Sand](../../spells/earthshape-sand.md)

## Effects

- Gain Sand Walk, increasing world map movement speed on sand.
- Able to build Farms on Sand terrain.
- Start in the desert.
- Unlock the Earthshape: Sand spell.

## Description

Moving around and settling in desert areas becomes easier.
They are used to the scorching desert sun.
