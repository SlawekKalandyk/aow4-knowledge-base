# Devious Watchers

- Type: society trait
- Point cost: 1
- Affinity: Shadow 1
- DLC: Base

## Effects

- Cities and Provinces have +2 Vision Range.
- Scout Units have Universal Camouflage.
- Outposts start with the Watch Tower upgrade built.

## Starting bonus

- Wayfinder Enchantment is already active and costs no upkeep.
- Start with an extra Scout Unit.

## Description

They are talented spies, sneaking past enemy lines to gain precious information.
