# Druidic Terraformers

- Type: society trait
- Point cost: 1
- Affinity: Nature 1
- DLC: Base

## Effects

- Cities gain ; +20% Food if the city core province contains Grasslands, Fungus Fields or Swamp.; +20% Production if the city core province contains Forest, Rocky or Mountains.; +10% Gold if the city core province contains Ashlands.; +10% Mana if the city core province contains Snow, Ice or Sand.
- Terraforming spells cost -25% less Mana and World Map Casting Point to cast.
- -20% Unit Upkeep for Elemental Units.

## Starting bonus

- Start with an extra Elemental unit.

## Description

Caretakers of the natural order, maintaining a carefully tended biome.
