# Gifted Casters

- Type: society trait
- Point cost: 1
- Affinity: Astral 1
- DLC: Base
- Incompatible with: Ancient Wise Ones

## Effects

- +10 Combat Casting Points
- +10 [World Map] World Map Casting Points.
- Combat Spells cost -20% less Mana to cast.

## Starting bonus

- Start with 1 extra Spell unlocked.

## Description

They are blessed with an innate talent for spellcasting, rarely encountering problems that can't be solved by an abundant use of magic.
